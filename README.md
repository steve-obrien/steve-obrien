# Steve O'Brien

**Founder, engineer and author. Building tools that help people turn ideas into working software.**

I'm a technical founder and full-stack software engineer based in Bristol, UK. I've spent more than two decades working across product, architecture and code. I previously founded and led [Newicon](https://newicon.net), a product engineering and digital transformation company, for 18 years.

[Website](https://steve-obrien.com) · [Writing](https://steve-obrien.com/articles) · [Projects](https://steve-obrien.com/projects) · [LinkedIn](https://www.linkedin.com/in/stevenaobrien/)

## What I'm building

- **[db3.ai Framework](https://github.com/db3ai/framework)**: I'm the creator and maintainer of this open-source TypeScript application framework. It brings models, authentication, queues, storage and AI into one runtime, so developers can build on shared foundations. [Framework documentation](https://db3.ai/framework).
- **[DOM Studio](https://getdom.studio)**: a Vue component library for building consistent interfaces, with documentation for developers and AI coding agents.
- **[GrowthScout](https://growthscout.io)**: AI-powered search intelligence that turns evidence into practical content strategy and action.
- **AI Test Engineer**: a project within db3.ai for running browser tests from natural-language briefs and reviewing the evidence.

## What I'm exploring

I want people to be able to describe a useful app, build it and check that it works. I'm exploring how to integrate the Codex harness into the db3.ai framework and its Studio offering, alongside agents that carry out work using application tools and data. Test Engineer is part of that direction: checking the result matters as much as generating it. The Codex integration is planned work.

I also write about AI, language models, software engineering and intelligence, and I'm working on **Intelligence: Human, Artificial, Future**, a book exploring how minds work, how machines think and what neuroscience may reveal about the future of intelligence.
