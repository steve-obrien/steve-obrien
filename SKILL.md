# Steve O'Brien Site

This repository is Steve O'Brien's personal site. It links to DOM Studio, growthscout.io

## Workflow

1. Keep site changes focused on the personal website, articles, projects, companies, news, and related static pages.
2. Use the existing Vue, Vite SSG, and Tailwind CSS patterns.
3. Use tabs for indentation.
4. Run `npm run build` after routing, page, SEO, or Vite config changes.
5. Treat `https://getdom.studio` as the canonical home for the former Elements framework.

## DOM Studio

Do not recreate framework files under `src/pages/elements`.

For DOM Studio docs and AI-facing instructions, use:

- `https://getdom.studio`
- `https://getdom.studio/llms.txt`
- the `getdom.studio` repository's `SKILL.md`

When this site needs to mention or link to the framework, point to `https://getdom.studio` or an equivalent deep link on that domain.
